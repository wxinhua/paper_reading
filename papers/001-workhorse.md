**Workhorse: Learning Robust Whole-Body Humanoid Loco-Manipulation from Human Data**

- **标签**：人类示范、全身移动操作、五部位接口、视觉规划、强化学习、闭环鲁棒性。

## 一句话理解

让人示范任务，用躯干、双腕、双脚的位姿连接视觉规划和全身控制，再用配套的数据增强处理两个模块互相造成的误差，驱动人形机器人完成动态接触任务。[论文摘要与 §IV](https://arxiv.org/html/2610.09117v1)

## 1. Motivation

已有运动跟踪器能执行给定动作，但操作时还需要机器人根据视觉决定下一步。遥操作依赖机器人和熟练操作者；人类示范更容易采集，却存在身体形态、视觉外观和执行误差的差异。本文关注的不只是走路时搬东西，还包括用脚踢、抵住物体、攀爬和扰动后的恢复。[论文 §I–II](https://arxiv.org/html/2610.09117v1)

**我的理解**：核心问题是“如何把人类的任务意图接到可维持平衡的机器人控制上”。接口必须兼顾任务几何与控制自由度；闭环误差不能只交给某一个模块承担。

## 2. 方法

### 2.1 整体结构

人类 RGB 与五部位运动 → 分别训练视觉规划器、全身跟踪器。

部署时：机器人 RGB 与身体历史 → 视觉规划器 → 五部位目标轨迹 → 全身跟踪器 → 关节位置设定值。两个模块共享接口，各自训练。[论文 Fig. 2、§IV](https://arxiv.org/html/2610.09117v1)

### 2.2 数据与接口

五个穿戴式追踪器加胸前相机；同一示范者采集箱子整理 **2.2 小时**、行李箱任务 **1.2 小时**、接箱 **13 分钟**。五部位目标只经固定刚体偏移对齐，不缩放人类运动。录制时用 IK 预览可达性。[官方项目页 Data / Alignment](https://hybridrobotics.github.io/workhorse/)

### 2.3 视觉规划器

输入 **4 帧图像、9 个五部位历史采样**，并保留重力方向与躯干高度。采用 flow matching / DiT，预测 **1.16 秒**目标片段，**5 Hz** 重规划。离线把图像中的人替换为机器人；训练时扰动历史、同步扭曲视图，但未来监督仍保持干净。[论文 §IV-B](https://arxiv.org/html/2610.09117v1)

### 2.4 全身跟踪器与部署

跟踪器基于 BeyondMimic，以 **50 Hz** 读取未来 **0.2 秒**目标和本体感觉，输出关节设定值。奖励强调腕部世界坐标精度，脚部相对躯干跟踪以留出平衡调整空间。训练加入指令漂移与重规划跳变；部署按观测时间戳跳过过期动作，并衔接相邻片段。[论文 §IV-C–D](https://arxiv.org/html/2610.09117v1)

**术语边界**：这里“不做 retargeting”指不缩放、改写五部位任务目标。IK 仍用于风格奖励、初始化、图像合成及采集预览；不应理解成整个系统完全不用 IK。[论文 §III-B、§IV-A、§IV-C.1](https://arxiv.org/html/2610.09117v1)

**我的理解**：最值得复用的是两种增强的配合：规划器学习从偏离的状态继续任务，跟踪器学习执行有漂移和跳变的指令。二者解决的是不同位置的分布变化。

## 3. 实验

### 3.1 真机能力展示

Unitree G1 展示三个任务：双手整理箱子并踢入底层；接住抛来的箱子；推、放倒并爬上行李箱取物。整理任务中展示受推、受踢、箱子被拿走后的继续执行。部署依赖机载视觉和本体感觉；规划器在外接笔记本上运行。**真机未报告系统成功率。**[论文 §V-A](https://arxiv.org/html/2610.09117v1)

### 3.2 仿真定量结果

在重建的示范房间中评估箱子整理，每个变体每种扰动条件 **100 回合**；成功定义是 **120 秒内放好全部三个箱子且不跌倒**。扰动为作用于骨盆、方向随机的 **40 N·s** 冲量：40 N 持续 1 秒，每 5–10 秒施加一次。[论文 Table II、§V-B](https://arxiv.org/html/2610.09117v1)

成功率（前者无推扰，后者有推扰）：

- **完整系统：77% / 64%。**
- 在线 IK 转关节指令：54% / 42%。
- 各部位自身坐标系表达动作：5% / 4%。
- 去掉重力方向与躯干高度：1% / 1%。
- 去掉规划器增强：20% / 0%。
- 去掉跟踪器指令增强：76% / 52%。

数值见 [官方项目页 Simulation](https://hybridrobotics.github.io/workhorse/)；“去掉重力”一项同时移除了高度，规划器增强也是整体移除，不能据此分离各子项贡献。

### 3.3 跨机器人与证据边界

复用同一批示范，**重新训练** H2 的两个模块，仿真无推扰成功率 **83%**。这证明了数据可复用，不等同于 G1 策略零样本迁移；H2 未做真机验证。[官方项目页 Cross-embodiment / Simulation](https://hybridrobotics.github.io/workhorse/)

完整系统有推扰跌倒率 **15%**，关节指令变体为 **4%**：任务成功率较高不代表所有安全指标都更好。77% 与 83% 的差异也不足以支持“H2 显著更好”。[论文 Table II、§V-B–C](https://arxiv.org/html/2610.09117v1)

**我的判断**：消融最有力地支持了身体状态信息、动作表达和训练分布对闭环表现的重要性。但多个因素一起移除的消融只能支持整体设计，不能给某个子机制单独分配功劳。

## 4. 结论与局限

本文展示了从人类示范到动态全身操作的一条可行路径。证据范围仍是单人、单房间、每任务独立策略；定量评估与 H2 结果来自仿真。五部位接口尚未覆盖手指与独立头部运动。[论文 §V–VI](https://arxiv.org/html/2610.09117v1)

**我的结论**：应将它看作接口与闭环训练设计的有价值实例。下一步需要分别检验任务泛化、场景泛化和真机可靠性，再讨论可扩展程度。

## 5. 研究启发与后续问题（阅读者判断）

1. **单独拆分增强**：保持其余设置一致，分别去掉历史漂移、视图扭曲、光度变化，判断谁在帮助恢复。
2. **把安全与完成率并列**：同时记录跌倒、任务进度、恢复时间和完成率，检查跟踪精度与平衡之间的取舍。
3. **检验数据可扩展性**：换人、换房间、换物体，分别测试；避免一次改变多项后无法解释失败。
4. **检验接口可扩展性**：加入手指状态、接触或力信息后，任务收益能否覆盖采集与学习成本？
5. **检验策略可复用性**：将多任务跟踪器与各任务独立跟踪器对比，区分数据复用和控制策略复用。

后续论文优先比较：数据采集约束、动作接口、是否重训练、闭环扰动协议、真机统计与场景变化。本文引用的 HuMI、BifrostUMI、BeyondMimic 可作为待阅读关联工作；本笔记未对它们作独立评价。
